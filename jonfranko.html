📊 Loan Default Predictive Modeling

MBA Capstone · Kent State University

Context

As part of my MBA coursework, I worked with a dataset of 80,000+ loan records and 763 variables. The objective was to design a predictive model that could help lenders better assess financial risk.

Problem

Traditional models often failed to accurately predict both:

  • Loan default likelihood (whether a borrower would default), and
  • Default loss amounts (the financial impact when a loan defaulted).

This limited decision-making accuracy for lenders managing large portfolios.

Solution

I developed a two-step predictive approach:

  • Classification model — to predict the probability of default.
  • Regression model (LASSO) — to estimate the expected loss when defaults occurred.
  • Combined methods improved overall accuracy.

Tools & techniques: Excel (data prep), R (regression), machine learning methods
Other research and analysis

Outcome

  • Reduced mean absolute error (MAE) from 5.2 → 1.72.
  • Delivered a model framework replicable by future cohorts.
  • Demonstrated how data-driven modeling can improve lender decision-making and reduce financial risk.
